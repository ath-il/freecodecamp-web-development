# Cat Blog Page

A simple cat blog webpage created as part of a freeCodeCamp HTML workshop.

## What I Learned

* Creating a webpage using HTML5
* Using semantic HTML elements like `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>`
* Adding images with `<img>`
* Using `<figure>` and `<figcaption>` for images
* Creating navigation links with `<nav>`
* Creating internal page links using `id` and `href`
* Adding contact information using `<address>`
* Creating phone and email links using `tel:` and `mailto:`

## Technologies Used

* HTML5
