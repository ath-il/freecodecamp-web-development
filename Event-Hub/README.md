# Event Hub

A simple event listing webpage created as part of a **freeCodeCamp HTML workshop**.

## What I Learned

* Creating a basic HTML document structure
* Using semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<article>`
* Creating navigation links with `<a>`
* Creating lists using `<ul>` and `<li>`
* Organizing upcoming and past events into sections
* Adding images using `<img>`
* Using `id` attributes for navigation between sections
* Writing accessible image descriptions with the `alt` attribute
