# Accessible Controls

A simple HTML page created as part of a **freeCodeCamp HTML workshop** to practice creating accessible audio controls.

## What I Learned

* Creating buttons using `<button>`
* Creating a volume slider using `<input type="range">`
* Using `aria-labelledby` to provide an accessible name and description for form controls
* Connecting multiple text elements to an input using their `id` attributes
* Building basic accessible user interface controls with HTML

## Technologies Used

* HTML5

## Project Features

* Play button
* Volume range control
* Volume label and description
* Mute button
* Accessibility support using ARIA attributes
