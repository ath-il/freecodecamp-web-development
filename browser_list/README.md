# List of Major Web Browsers

A simple HTML webpage created as part of a freeCodeCamp workshop. The project displays a list of major web browsers along with a short description of each browser.

## What I Learned

* Creating a basic HTML document structure
* Using headings with `<h1>`
* Using description lists with `<dl>`
* Using `<dt>` to define each browser name
* Using `<dd>` to provide a description for each browser
* Adding responsive viewport settings with the `<meta>` tag

## Browsers Included

* Google Chrome
* Firefox
* Safari
* Brave
* Arc
