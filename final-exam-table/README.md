# Final Exam Table

A simple HTML table created as part of a **freeCodeCamp HTML workshop** to practice creating and structuring tables.

## What I Learned

* Creating tables using `<table>`
* Adding a table title using `<caption>`
* Structuring headers with `<thead>`
* Adding table rows using `<tr>`
* Using `<th>` and `<td>` for table cells
* Organizing data with `<tbody>`
* Creating a footer using `<tfoot>`
* Using `colspan` to merge table columns

## Technologies Used

* HTML5
