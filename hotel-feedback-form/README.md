# Hotel Feedback Form

A simple **Hotel Feedback Form** built with HTML as part of a **freeCodeCamp workshop**.

## What I Learned

* Creating a basic HTML document structure
* Using semantic elements such as `<header>`, `<main>`, and `<form>`
* Creating forms with the `<form>` element
* Grouping related form controls using `<fieldset>` and `<legend>`
* Creating text, email, and number inputs
* Using `required`, `placeholder`, `min`, `max`, and `size` attributes
* Creating radio buttons for selecting one option
* Creating checkboxes for selecting multiple options
* Creating dropdown menus with `<select>` and `<option>`
* Using `<textarea>` for longer comments
* Creating a submit button with `<button>`
* Connecting `<label>` elements to form controls using `for` and `id`
* Setting default selections using `checked` and `selected`
* Using the `method` and `action` attributes in a form

## Project

The form collects:

* Personal information
* First-time hotel stay information
* Reasons for choosing the hotel
* Service and food ratings
* Additional comments

## Technologies Used

* HTML5

This project was created while learning HTML through **freeCodeCamp**.
