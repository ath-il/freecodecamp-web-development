# HTML Audio and Video Lab

A simple HTML webpage created as part of a freeCodeCamp workshop to practice using HTML audio and video elements.

## What I Learned

* Using the `<video>` element
* Using the `<audio>` element
* Adding controls to audio and video
* Using the `<source>` element
* Working with external media files
* Using HTML attributes such as `width`, `controls`, and `loop`

## Technologies Used

* HTML5
