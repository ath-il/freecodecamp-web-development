# Multimedia Player

A simple HTML multimedia player created as part of a **freeCodeCamp workshop**.

## Features

* 🎵 Audio player with playback controls.
* 🎬 Video player with playback controls.
* 💬 Subtitle track for the video.
* 📝 Transcript section.
* ♿ Basic accessibility features using semantic HTML and ARIA labels.

## HTML Concepts Practiced

* `<audio>` — Embeds audio content into a webpage.
* `<video>` — Embeds video content into a webpage.
* `<source>` — Specifies media files for audio and video elements.
* `<track>` — Provides timed text such as subtitles or captions for video.
* `controls` — Displays the browser's built-in media controls.
* `aria-label` — Provides an accessible name for media elements.
* `<section>` — Groups related content into meaningful sections.
* `<h1>` and `<h2>` — Create a semantic heading structure.
