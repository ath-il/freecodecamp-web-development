# Quincy's Tips for Getting a Developer Job

A simple HTML webpage based on Quincy Larson's tips for getting a developer job, created as part of a freeCodeCamp workshop.

## What I Learned

* Using semantic HTML elements such as `<main>` and `<section>`
* Creating headings with `<h1>` and `<h2>`
* Using `<p>` for paragraphs
* Using `<q>` for short inline quotations
* Using `<blockquote>` for longer quotations
* Using the `cite` attribute to provide the source of a quotation
* Using `<cite>` to identify the title of a referenced work
* Using `&mdash;` to create an em dash in HTML
* Structuring a webpage with meaningful semantic elements
