# FreeCodeCamp Recipe Page

A basic recipe webpage created while learning the fundamentals of HTML through freeCodeCamp.

The webpage contains a recipe title, description, ingredients list, cooking instructions, and a recipe image.

## What I Learned

In this project, I practiced using the following HTML elements:

* `<!DOCTYPE html>` — Declares the document as HTML5
* `<html lang="en">` — Defines the HTML document and specifies English as the language
* `<head>` — Contains information about the webpage
* `<title>` — Sets the title of the webpage
* `<meta charset="UTF-8">` — Sets the character encoding
* `<body>` — Contains the visible content of the webpage
* `<h1>` — Creates the main recipe heading
* `<h2>` — Creates section headings
* `<p>` — Adds a paragraph describing the recipe
* `<ul>` — Creates an unordered list for ingredients
* `<li>` — Defines individual list items
* `<ol>` — Creates an ordered list for instructions
* `<img>` — Displays an image
* `alt` attribute — Provides alternative text for the image

## Technologies

* HTML5

## Project Structure

The webpage is organized into three main sections:

1. **Recipe** — Contains the main heading and description.
2. **Ingredients** — Contains a list of ingredients using `<ul>`.
3. **Instructions** — Contains step-by-step instructions using `<ol>`.

A recipe image is displayed at the bottom of the page using the `<img>` element.

The purpose of this project was to practice basic HTML syntax, document structure, headings, paragraphs, lists, images, and HTML attributes.
