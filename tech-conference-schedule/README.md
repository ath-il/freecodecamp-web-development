# Tech Conference 2025 Schedule

A simple HTML table that displays the schedule for a fictional Tech Conference 2025, organized by time and conference track.

## What I Learned

* Creating tables using `<table>`
* Adding table captions using `<caption>`
* Structuring tables with `<thead>` and `<tbody>`
* Creating table rows using `<tr>`
* Using `<th>` for table headings
* Using `<td>` for table data
* Using `scope="col"` and `scope="row"` for better table accessibility
* Using `colspan` to make a cell span across multiple columns

## Technologies Used

* HTML5

## Project

This project was created as part of a **freeCodeCamp HTML workshop** to practice creating accessible and structured HTML tables.
