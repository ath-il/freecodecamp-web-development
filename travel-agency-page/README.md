# Travel Agency Page

A simple travel agency webpage created as part of a freeCodeCamp HTML workshop.

## What I Learned

* Basic HTML document structure
* Headings using `<h1>` and `<h2>`
* Paragraphs using `<p>`
* Creating links using `<a>`
* Creating lists using `<ul>` and `<li>`
* Adding images using `<img>`
* Using `<figure>` and `<figcaption>`
* Using `alt` attributes for images
* Using `target="_blank"` for links
* Adding a meta description

## Technologies

* HTML5

## Learning Source

This project was created as part of my HTML learning journey through freeCodeCamp.

## Project

The webpage represents a simple travel agency page featuring:

* Travel packages
* Group travel and private tours
* Top travel itineraries
* Destination images
* Captions for travel destinations
