# Video Compilation Page

A simple HTML webpage created as part of a freeCodeCamp workshop.

## What I Learned

* Creating a webpage using basic HTML structure
* Using semantic elements such as `<main>` and `<section>`
* Creating headings with `<h1>` and `<h2>`
* Adding paragraphs using `<p>`
* Embedding videos or external content using `<iframe>`
* Using iframe attributes such as `src`, `title`, `height`, and `width`

## Output

🎬 A webpage that organizes front-end web development topics into separate sections with embedded video areas.
