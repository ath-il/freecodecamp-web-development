# XYZ Bookstore Page

A simple bookstore webpage created as part of a freeCodeCamp HTML workshop.

## What I Learned

- Basic HTML document structure
- Headings using `<h1>` and `<h2>`
- Paragraphs using `<p>`
- Containers using `<div>`
- Using `class` and `id` attributes
- Creating buttons using `<button>`
- Structuring content with HTML elements

## Technologies

- HTML5

## Learning Source

This project was created as part of my HTML learning journey through freeCodeCamp.

## Project

The webpage represents a simple bookstore containing:

- Two book cards
- Book descriptions
- "Buy Now" buttons
- "View Cart" and "Checkout" buttons
